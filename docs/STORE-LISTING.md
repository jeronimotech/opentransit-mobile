# Store listing copy

One worldwide listing for **opentransit**, localised into seven languages. This replaces the
Bogotá-only listing: there is no longer a per-city listing, and the app name no longer carries
a city.

The honesty rule has not changed. **Nothing here promises a feature the app does not have.**
Check every claim against the build before publishing, and cut anything that has since changed.
Two claims in particular are store-policy risks rather than style choices:

- **opentransit is not the official app of any transit agency.** It reads the open data agencies
  publish. No wording may imply endorsement, affiliation or officialdom.
- **Realtime is not everywhere.** Casablanca and Santiago are timetable-only, because no open
  realtime feed exists there. The app says so on screen, and so does this copy.

Support and marketing URLs, all three live:

- Marketing / project: `https://opentransit.tech`
- Support: `https://bogota.opentransit.tech/bogota`
- Privacy: `https://bogota.opentransit.tech/bogota/privacy`

| French (France) | `fr-FR` | also serves Morocco |
| Italian | `it-IT` | Roma |
| Malay | `ms-MY` | Kuala Lumpur |
| Arabic | `ar` | Play has no per-country Arabic |

**English (`en-US`) is the default listing language.** Every country without a localised
listing sees the English one, so it has to read as a global listing rather than a US one — that
is why it names all nine cities and leads with "nine cities", not with the MBTA.

App Store Connect uses the equivalent App Store localisations (Spanish (Mexico) or Spanish
(Spain) for `es-419`, Portuguese (Portugal), French, Italian, Malay, Arabic) with English (U.S.)
as the primary language.

Modes, by city: bus, metro/subway, commuter rail, tram/streetcar, ferry, cable car, shared bikes
(GBFS), taxi and ride-hailing hand-off, park-and-ride.

# What changed

This file replaces the Bogotá-only listing ("opentransit Bogotá", Spanish first, TransMilenio in
the subtitle). What is different:

1. **One worldwide listing, not one per city.** The name no longer carries a city, so the same
   store entry serves all nine. Keywords are the only field that leans local, and they lean to
   the country each locale actually reaches.
2. **Seven languages instead of two** (Spanish, English, Portuguese (Portugal), French, Italian,
   Malay, Arabic), with both stores fully specified in each.
3. **Play and App Store descriptions are now separate texts.** The old file reused the App Store
   description for Play; the Play full description is now written to be skimmed, with plain
   headings and no markdown symbols, since Play renders none.
4. **New features named:** scheduled trips, follow-along with Live Activities, Dynamic Island and
   Apple Watch, shareable ETA link, shared bikes in four cities, taxi and ride-hailing hand-off,
   estimated fares, park-and-ride.
5. **Two new honesty statements:** Casablanca and Santiago are timetable-only, and opentransit is
   not the official app of any agency. Both appear in every locale, in both stores.
